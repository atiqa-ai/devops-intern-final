Loki Monitoring Setup
=====================

Loki is used for centralized log aggregation in this project.

Components:
- Loki: Stores application/container logs.
- Promtail: Collects Docker container logs and forwards them to Loki.
- Grafana: Queries and visualizes logs from Loki.

Docker services:
- Loki: grafana/loki:latest
- Promtail: grafana/promtail:latest
- Grafana: grafana/grafana:latest

Loki URL:
http://localhost:3100

Grafana URL:
http://localhost:3000

Promtail forwards Docker logs to:

http://loki:3100/loki/api/v1/push

Logs can be viewed in Grafana using the Loki datasource.

Example LogQL query:

{job="docker"} |= "hello-app"

The query displays logs generated by the Nomad-managed application
containers.

The application is deployed through Nomad with two running allocations.
Nomad dynamically assigns ports to the application containers, while
Promtail collects their Docker logs for Loki.

Monitoring flow:

Nomad -> Docker containers -> Promtail -> Loki -> Grafana
