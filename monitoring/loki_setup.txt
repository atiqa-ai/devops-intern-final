Loki Monitoring Setup
=====================

Project: DevOps Intern Final Assessment
Name: Atiqa Mushtaq
Date: 12 August 2026

1. Overview
-----------

Grafana Loki was added as an additional monitoring/logging component
to the DevOps project.

Docker container logs are collected by Promtail and forwarded to Loki.
Grafana is connected to Loki as a data source and is used to query and
visualize the collected logs.

The monitoring flow is:

Docker Containers
       |
       v
   Docker JSON Logs
       |
       v
    Promtail
       |
       v
      Loki
       |
       v
    Grafana


2. Loki
-------

Loki is running locally on port 3100.

Loki API health check:

curl -s http://localhost:3100/ready

The expected response is:

ready


3. Promtail
-----------

Promtail reads Docker container JSON log files from:

/var/lib/docker/containers/*/*-json.log

The Promtail configuration is stored in:

monitoring/promtail-config.yml

Promtail forwards logs to:

http://loki:3100/loki/api/v1/push


4. Verify Loki Labels
---------------------

The following command lists available Loki labels:

curl -s http://localhost:3100/loki/api/v1/labels

The project currently exposes labels including:

filename
job
service_name


5. Verify Docker Logs in Loki
-----------------------------

The Docker log label can be checked with:

curl -s http://localhost:3100/loki/api/v1/label/job/values

The expected result includes:

docker


6. Query Logs
-------------

Loki range queries are used to retrieve log entries.

Example:

curl -sG 'http://localhost:3100/loki/api/v1/query_range' \
  --data-urlencode 'query={job="docker"}' \
  --data-urlencode 'limit=20'


7. Query hello-app Logs
-----------------------

Example LogQL query:

{job="docker"} |= "hello-app"

This query filters Docker logs collected by Promtail and searches
for entries containing "hello-app".


8. Grafana
----------

Grafana is connected to Loki as a data source.

Grafana uses Loki's query_range API when displaying log data.

Example query used in Grafana:

{job="docker"} |= "hello-app"


9. Verification
---------------

The monitoring pipeline was verified successfully.

Loki returned successful query responses with:

status = success

Grafana also successfully received and parsed responses from Loki.

This confirms the following pipeline is working:

Docker -> Promtail -> Loki -> Grafana


10. Additional Monitoring
------------------------

Prometheus was also added to the project as an additional monitoring
component.

Prometheus configuration is stored in:

monitoring/prometheus/prometheus.yml

The application exposes Prometheus-compatible metrics at:

http://localhost:8000/metrics

The application currently exposes:

app_running 1

app_info{app="devops-intern"} 1
