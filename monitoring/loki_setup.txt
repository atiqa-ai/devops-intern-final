Loki Monitoring Setup
=====================

Loki provides centralized log aggregation for the project.

Components
----------

- Loki: Stores and serves logs.
- Promtail: Collects Docker container logs and forwards them to Loki.
- Grafana: Queries and visualizes logs from Loki.

Services
--------

Loki       : grafana/loki:latest
Promtail   : grafana/promtail:latest
Grafana    : grafana/grafana:latest

Endpoints
---------

Loki       : http://localhost:3100
Grafana    : http://localhost:3000

Log Flow
--------

Nomad
  |
  v
Docker Containers
  |
  v
Promtail
  |
  v
Loki
  |
  v
Grafana

Promtail forwards logs to:

http://loki:3100/loki/api/v1/push

LogQL Example
-------------

{job="docker"} |= "hello-app"

This query filters logs generated by the application containers managed
by Nomad.

Verification
------------

The project runs two Nomad application allocations. Their Docker logs
are collected by Promtail and forwarded to Loki, where they can be
queried through the Loki datasource in Grafana.
Nomad dynamically assigns ports to the application containers, while
Promtail collects their Docker logs for Loki.

Monitoring flow:

Nomad -> Docker containers -> Promtail -> Loki -> Grafana
EOF
